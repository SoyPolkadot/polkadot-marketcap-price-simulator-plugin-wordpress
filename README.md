# polkadot-marketcap-price-simulator-plugin-wordpress
 Polkadot Price Simulator allows users to explore hypothetical price scenarios based on Polkadot’s potential market capitalization compared to other leading cryptocurrencies. Is a wordpress plugin


**Versión Bilingüe (Español e Inglés)**

Este plugin de WordPress permite simular escenarios de precio de Polkadot (DOT) basados en diferentes capitalizaciones de mercado.

## Características

- Simulador de precio de Polkadot.
- Opciones para comparar con otras criptomonedas o ingresar una capitalización personalizada.
- Versión bilingüe: Español e Inglés.

## Instalación

1. Descarga el archivo `polkadot-simulator.php`.
2. Crea una carpeta en `wp-content/plugins/` llamada `polkadot-simulator`.
3. Coloca el archivo `polkadot-simulator.php` en la carpeta.
4. Activa el plugin desde el panel de administración de WordPress.

## Uso

- Para la versión en español, utiliza el shortcode: `[polkadot_simulator]`.
- Para la versión en inglés, utiliza el shortcode: `[polkadot_simulator_en]`.

## Nota

- Esta versión del plugin utiliza datos de ejemplo y no está conectada a ninguna API.
- Para obtener datos en tiempo real, es necesario integrar una API.
